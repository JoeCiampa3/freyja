# sim/runs/

One directory per run, named from the run id without `run.` (`20261012-1430-hold_pose/`):

- `summary.json` the run record (`run-summary/1`, schema in `docs/schemas/`). Small, text-only, tracked in git.
- `raw.npz` the time series. Gitignored.

`DIGEST.md` (latest run per scenario) and `ENVELOPE.md` (worst case per joint across scenarios) are generated by
`fy runs digest` and `fy runs envelope`; do not edit them. `MUJOCO_LOG.TXT` is MuJoCo's own log (gitignored).
